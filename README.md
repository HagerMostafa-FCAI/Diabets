# Diabets
# 🩺 Diabetes Risk & Health Metrics Analysis

A comprehensive end-to-end data analysis project focusing on multi-factor diabetes risk evaluation, combining robust database querying, data preprocessing, and an interactive business intelligence dashboard.

---

## 🚀 About the Project
This project investigates health indicators, patient demographics, and clinical risk factors associated with diabetes. By leveraging multiple tools across the data stack, it transforms raw data into actionable insights and visual key performance indicators (KPIs).

---

## 🛠️ Tech Stack & Tools
* **Data Visualization:** Power BI (Interactive Dashboard for Multi-Factor Risk Analysis)
* **Database & Querying:** SQL (Advanced data manipulation, joins, aggregations, and conditions)
* **Data Processing & Analysis:** Python (Notebooks for data preprocessing and exploration)
* **Version Control:** Git & GitHub
