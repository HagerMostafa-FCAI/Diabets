## 🚀 About the Project
This project investigates health indicators, patient demographics, and clinical risk factors associated with diabetes. By leveraging multiple tools across the data stack, it transforms raw data into actionable insights and visual key performance indicators (KPIs).

---

## 🛠️ Tech Stack & Tools
* **Data Visualization:** Power BI (Interactive Dashboard for Multi-Factor Risk Analysis)
* **Database & Querying:** SQL (Advanced data manipulation, joins, aggregations, and conditions)
* **Data Processing & Analysis:** Python (Notebooks for data preprocessing and exploration)
* **Version Control:** Git & GitHub

---

```text

## 💻 SQL Queries & Analysis
This section highlights the database operations and querying techniques utilized to extract insights:
* **Data Manipulation & Joins:** Combined multiple tables to evaluate clinical metrics and patient records.
* **Aggregations & Conditions:** Implemented `CASE` statements and filtering to categorize risk levels and demographic segments.
* *You can check the complete scripts inside the [SQL](https://github.com/HagerMostafa-FCAI/Diabets/tree/main/SQL) directory.*

---

## ⚙️ How to Explore the Project
1. **Power BI:** Open the `.pbix` file located in the `Dashboards` folder to interact with the visual metrics.
2. **SQL Queries:** Review the database schemas and scripts inside the `SQL` folder.
3. **Python Notebooks:** Check the `Notebooks` directory for data preprocessing and exploration workflows.
